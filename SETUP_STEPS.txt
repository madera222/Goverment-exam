📚 COMPUTER BASED EXAM SYSTEM - SETUP STEPS

=== STEP 1: DOWNLOAD અને EXTRACT ===

1. ZIP FILE DOWNLOAD કરો:
   - exam-system.zip download કરો
   
2. EXTRACT કરો:
   - Windows: Right-click → Extract All
   - Mac: Double-click
   - Linux: unzip exam-system.zip

3. FOLDER STRUCTURE:
   exam-system/
   ├── index.html
   ├── style.css
   ├── script.js
   ├── QUICK_START_GU.md
   ├── README.md
   ├── FEATURES_AND_SETUP.md
   └── data/
       ├── questions.json (30 પ્રશ્નો)
       └── questions-extended.json (150 પ્રશ્નો)

=== STEP 2: SERVER શરુ કરો ===

વિકલ્પ 1: Python (સરળતમ - આમાં Python હોય તો)
─────────────────────────────
1. Terminal/CMD ખોલો
2. Type કરો: cd exam-system
3. Type કરો: python -m http.server 8000
4. Output: Serving HTTP on 0.0.0.0 port 8000
5. Done! ✓

વિકલ્પ 2: Node.js HTTP Server
─────────────────────────────
1. Terminal ખોલો
2. Type કરો: cd exam-system
3. Type કરો: npx http-server
4. Copy કર્યો લિંક (http://127.0.0.1:8080)
5. Browser માં પેસ્ટ કરો

વિકલ્પ 3: VS Code Live Server
─────────────────────────────
1. VS Code ખોલો
2. Open Folder → exam-system/ પસંદ કરો
3. index.html રાઇટ-ક્લિક → Open with Live Server
4. Automatically browser ખુલશે

=== STEP 3: BROWSER ખોલો ===

1. Browser URL bar માં લખો:
   http://localhost:8000

2. Page load થાય છે તે જાણો
   (Page લોડ થવા માટે થોડો સમય લાગી શકે છે)

3. "કમ્પ્યુટર આધારિત પરીક્ષા સિસ્ટમ" વાચો

=== STEP 4: EXAM શરુ કરો ===

1. Exam Set પસંદ કરો (1-20):
   ✓ ડ્રોપડાઉન ખોલો
   ✓ Exam Set 1 select કરો

2. Settings configure કરો:
   ✓ Time: 30 (મિનિટમાં)
   ✓ Questions: 30 (કેટલાં પ્રશ્નો)

3. બટન દબાવો: "પરીક્ષા શરુ કરો"

=== STEP 5: QUESTIONS લોડ કરો ===

બીજો મહત્તવનો: data/questions.json માં પોતાના પ્રશ્નો ઉમેરો

JSON Structure:
───────────────
{
  "questions": [
    {
      "id": 1,
      "question": "પ્રશ્ન લખો?",
      "options": [
        "વિકલ્પ 1",
        "વિકલ્પ 2",
        "વિકલ્પ 3",
        "વિકલ્પ 4"
      ],
      "correctAnswer": 0,
      "category": "web"
    }
  ]
}

⚠️ IMPORTANT:
- correctAnswer = 0 (પ્રથમ વિકલ્પ)
- correctAnswer = 1 (બીજો વિકલ્પ)
- options હંમેશા 4 હોવા જોઈએ
- JSON valid હોવો જોઈએ

=== STEP 6: 150 પ્રશ્નો ઉમેરવા ===

Option 1: Pre-made 150 questions વાપરો
─────────────────────────────────────

=== TROUBLESHOOTING ===

❌ Questions લોડ નથી થતા
✓ Solution:
  1. Browser console ખોલો (F12)
  2. Errors જોવો
  3. data/questions.json ચેક કરો
  4. JSONLint.com વાપરીને validate કરો

❌ Server error આવે છે
✓ Solution:
  1. Port 8000 available છે?
  2. અલગ port વાપરો: python -m http.server 9000
  3. Browser હટાવો અને ફરી start કરો

❌ Exam start નથી થતો
✓ Solution:
  1. Exam Set select કર્યો છે?
  2. Time > 5 minute છે?
  3. JavaScript enable છે?

❌ Scores calculate નથી થતા
✓ Solution:
  1. Console errors ચેક કરો
  2. JavaScript enable છે?
  3. Browser refresh કરો
